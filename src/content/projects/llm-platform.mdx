## 问题

随着内部多个 Agent 与检索管线演进，答案生成、相关性判断与重排、查询优化、上下文路由等阶段的模型配置分散在环境变量与代码中，且调用点存在模块级模型单例串用、阶段关闭后后续分支误调用，以及 Embedding 模型/向量维度被随意修改破坏索引兼容性的痛点。

## 方案

- **多级配置解析与请求级隔离**：建立“请求级覆盖 > 应用级配置 > 环境默认值”的按字段合并机制，将 `temperature`、`maxTokens`、`timeout` 等参数准确透传至实际调用，并彻底消除模块级模型单例跨应用串用。
- **Provider 安全治理与真实拓扑画布**：支持自定义 Provider、OpenAI-compatible 接口、连接测试与模型发现，建设凭据加密存储、界面掩码展示与删除前应用引用检查；以后端真实执行拓扑驱动 React Flow 可视化画布，并将 Embedding 连接配置独立锁定以保障向量索引兼容。

## 结果

打通应用级分阶段模型路由与可视化管理闭环，并接入 Datadog Agent Observability（`run_id` 评分反馈闭环），支撑内部多 Agent 系统的模型灵活切换与可观测治理。
